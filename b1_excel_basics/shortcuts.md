# Excel-Tastenkürzel – die wichtigsten auf einen Blick

Zurück zum Kapitel: [Excel Grundlagen](./README.md)

> ⭐ = brauchen wir bereits an **Tag 1**. Gilt für Excel unter **Windows** mit deutscher Oberfläche und Schweizer Tastatur. Hinweise für Mac und Laptops am Schluss.
>
> **Tipp:** Drücken Sie **Alt** – im Menüband erscheinen Buchstaben. Damit erreichen Sie jeden Befehl per Tastatur, ohne ein Kürzel auswendig zu kennen.

---

## 1. Die Top 10 für den Baustellen-Alltag

| **Tasten**          | **Wirkung**                                                                  |     |
| ------------------- | ---------------------------------------------------------------------------- | --- |
| **F2**              | Zelle bearbeiten – zeigt die Formel und färbt die verwendeten Zellen         | ⭐   |
| **F4**              | Bezug fixieren: `B2` → `$B$2` → `B$2` → `$B2` (beim Bearbeiten einer Formel) | ⭐   |
| **Ctrl+1**          | Zellen formatieren (Zahl, Datum, `[hh]:mm`, Rahmen …)                        | ⭐   |
| **Alt+Shift+0**     | AutoSumme (= Alt + Gleichheitszeichen)                                       | ⭐   |
| **Ctrl+Z / Ctrl+Y** | Rückgängig / Wiederherstellen                                                | ⭐   |
| **Ctrl+S**          | Speichern                                                                    | ⭐   |
| **Ctrl+H**          | Ersetzen (z. B. " km" entfernen, "." durch ":" ersetzen)                     | ⭐   |
| **Ctrl+Pfeiltaste** | An den Rand der Daten springen                                               | ⭐   |
| **Ctrl+Alt+V**      | Inhalte einfügen – z.B. **nur Werte** ohne Formeln                           |     |
| **Ctrl+T**          | Bereich als Tabelle formatieren (mit Filter und Formatvorlage)               |     |

## Hinweise

**Laptop:** Die Funktionstasten F1–F12 sind oft mit Lautstärke, Helligkeit usw. belegt. Dann zusätzlich die **Fn**-Taste drücken: **Fn+F2**, **Fn+F4**, **Fn+F11**. Bei manchen Geräten lässt sich das mit **Fn+Esc** umschalten.

**Mac:** Statt Ctrl meist **Cmd**. Abweichungen: Bezug fixieren **Cmd+T** (statt F4), Zelle bearbeiten **Ctrl+U** (statt F2), Zellen formatieren **Cmd+1**, AutoSumme **Cmd+Shift+T**.

**Excel im Browser:** Viele Kürzel funktionieren auch dort, einige werden aber vom Browser abgefangen (z. B. Ctrl+N, Ctrl+W). Für den Kurs die **Desktop-Version** verwenden.
