# 1. Excel Kalkulation – Küchenrenovation

> **In Erarbeitung** – Unterrichtspaket Tag 2 folgt (Theorie, Übungen, Übungsdateien in `./x_gitres`).

## 1.1. Lernziele

Nach diesem Kapitel können Sie:

- [ ] eine Kalkulationstabelle mit Mengen, Einheiten und Einheitspreisen aufbauen
- [ ] Lohnkosten, MWST und Reserve mit Bezügen auf eine Legende berechnen
- [ ] Annahmen und offene Positionen in einem Grobbudget kennzeichnen
- [ ] Summen und Formeln einer fremden Kalkulation prüfen

---

## 1.2. Ablauf

**Projekt:** Küchenrenovation

| **Phase**     | **Inhalt**                                                                          |
| ------------- | ----------------------------------------------------------------------------------- |
| Einstieg      | Rückblick Tag 1 (Transferauftrag), von der Reiseplanung zur Baukalkulation wechseln |
| Demonstration | Menge × Einheitspreis, Lohnkosten, MWST und Reserve                                 |
| Übung         | Positionen für Küche, Elektro, Sanitär und Montage erfassen                         |
| Projektarbeit | Grobbudget mit Annahmen und offenen Positionen erstellen                            |
| Sicherung     | Summen und Formeln gegenseitig prüfen                                               |
