# S1 Word – Dokumentationen erstellen

> **Selbststudium** – zählt nicht als Kursabend. Bearbeitung: **nach Tag 2, spätestens vor Tag 4**.

## Lernziele

Nach dieser Einheit können Sie:

- [ ] Dokument aufbauen mit Formatvorlagen und Überschriften
- [ ] Inhaltsverzeichnis automatisch erstellen
- [ ] Bilder und Tabellen einfügen und beschriften
- [ ] Quellen angeben
- [ ] Kopf- und Fusszeile mit Seitenzahl gestalten

## Auftrag und Abgabe

| **Vorgabe**         | **Beschreibung** |
| :------------------ | :--------------- |
| **Sozialform**      | Einzelarbeit     |
| **Zeitbedarf**      | ca. 3–4 h        |
| **Abgabe**          | Kurzdokumentation mit Deckblatt, Überschriften, Tabelle, Bild, Quelle und Seitenzahl |

| **Kontrolle im Kurs** | Tag 4: kurzer Offertenbericht. Tag 7: vollständige Projektdokumentation. |
