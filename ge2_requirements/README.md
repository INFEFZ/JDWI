## Hinweise

- Für Excel wird die **Desktop-Version** empfohlen. Excel im Browser unterstützt nicht alle Funktionen (z. B. PivotChart mit F11).
- Mac-Nutzer: Tastenkürzel weichen ab (z. B. **Cmd+T** statt F4 für absolute Bezüge).
- ProjectLibre benötigt eine Java-Laufzeit (wird bei der Installation mitgeliefert bzw. angefordert).
- Keine echten Kunden- oder Personendaten in KI-Werkzeuge eingeben (siehe Tag 4).
